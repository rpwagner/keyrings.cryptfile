# Security policy

## Supported versions

Security fixes are provided for the latest released version of
`keyrings.cryptfile`.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use **Report a vulnerability** on the repository's **Security** page to submit
a private report. Include:

- the affected version;
- a clear description of the issue and its potential impact;
- steps or a minimal example that reproduce the issue; and
- any suggested mitigation, if known.

The maintainer will acknowledge the report, investigate it, and coordinate a
fix and disclosure when appropriate.

Ordinary defects and compatibility problems that do not have a security impact
may be reported through the public issue tracker.
